# Análise de Vendas e Desempenho de Vendedores — Excel

<img width="1317" height="600" alt="image" src="https://github.com/user-attachments/assets/9c7dcc97-c2b2-4752-8508-3639c448eefa" />

Dashboard desenvolvido no **Microsoft Excel** para análise de vendas e desempenho comercial, permitindo acompanhar o faturamento, a quantidade de vendas e o desempenho dos vendedores ao longo dos meses.

O projeto foi desenvolvido com o objetivo de transformar uma base de dados de vendas em uma ferramenta visual e interativa, facilitando a análise dos resultados por **ano, mês e vendedor**.

---

## Objetivo do Projeto

O objetivo deste projeto foi desenvolver um **dashboard interativo de vendas no Microsoft Excel**, utilizando recursos de organização, análise e visualização de dados.

O dashboard permite analisar:

- Faturamento mensal;
- Quantidade de vendas por mês;
- Ranking dos vendedores;
- Faturamento dos vendedores;
- Participação do melhor vendedor nas vendas;
- Desempenho dos vendedores em um mês específico;
- Comparação entre o melhor vendedor e os demais;
- Análise das vendas por ano.

---

## Dados Utilizados

A base de dados contém informações sobre as vendas realizadas, incluindo a data da venda, ano, mês, vendedor, produto, valor do produto, quantidade vendida e valor total da venda.

### Estrutura da Base de Dados

| Campo | Descrição |
|---|---|
| Data | Data em que a venda foi realizada |
| Ano | Ano correspondente à venda |
| Mês | Mês correspondente à venda |
| Vendedor | Vendedor responsável pela venda |
| Produto | Produto vendido |
| ValorProd | Valor unitário do produto |
| QuantVend | Quantidade de unidades vendidas |
| TotalVend | Valor total da venda |

---

## Dashboard

O dashboard apresenta uma visão geral do desempenho das vendas e permite realizar análises de forma visual e interativa.

Na parte superior são apresentados os **principais vendedores do período selecionado**, acompanhados de seus respectivos valores de vendas e posições no ranking.

---

## Ranking de Vendedores

O ranking apresenta os vendedores de acordo com o valor total de vendas no período selecionado.

O ranking é atualizado de acordo com o **ano selecionado no dashboard**.

---

## Vendas por Mês em Valor

O gráfico de **Vendas por mês em valor** apresenta o faturamento total de cada mês do ano selecionado.

Essa análise permite identificar:

- Meses com maior faturamento;
- Meses com menor faturamento;
- Variações nas vendas ao longo do ano;
- Evolução do desempenho comercial.

---

## Vendas por Mês em Quantidade

O gráfico de **Vendas por mês em quantidade** apresenta a quantidade total de produtos vendidos em cada mês.

A visualização permite comparar o volume de vendas ao longo do ano e identificar os meses com maior e menor quantidade de produtos vendidos.

---

## Melhor Vendedor vs. Restante

O gráfico de **Melhor Vendedor vs. Restante** apresenta a participação do vendedor com maior faturamento em comparação aos demais vendedores.

Essa visualização permite observar quanto o melhor vendedor representa do total de vendas analisado.

---

## Análise por Ano e Mês

Uma das principais funcionalidades do dashboard é a possibilidade de realizar análises utilizando filtros.

### Filtro por Ano

O dashboard possui um filtro para selecionar o **ano que será analisado**.

Ao selecionar um ano, as informações do dashboard são atualizadas para apresentar os dados correspondentes àquele período.

Anos disponíveis:

- 2018
- 2019
- 2020

### Filtro por Mês

Também é possível selecionar um **mês específico** para analisar as vendas daquele período.

Ao selecionar um mês, a **Tabela de Vendas** é atualizada, apresentando o valor vendido por cada vendedor especificamente naquele mês.

Por exemplo, ao selecionar **novembro**, é possível visualizar quanto cada vendedor vendeu durante o mês de novembro.

---

## Tabela de Vendas

A **Tabela de Vendas** apresenta o valor vendido por cada vendedor de acordo com o mês selecionado.

Essa tabela permite comparar diretamente o desempenho dos vendedores em um período específico.

É possível identificar:

- Vendedor com maior faturamento no mês;
- Vendedor com menor faturamento no mês;
- Diferença de vendas entre os vendedores;
- Desempenho individual em determinado período.

## Interatividade

O dashboard permite explorar os dados de maneira dinâmica.

A partir dos filtros disponíveis, é possível:

**1. Selecionar o ano:** visualizar o desempenho das vendas daquele ano.

**2. Selecionar o mês:** analisar especificamente as vendas realizadas naquele mês.

**3. Alterar os filtros:** atualizar os indicadores, gráficos, ranking e tabela de vendas de acordo com o período selecionado.

Dessa forma, o dashboard permite realizar tanto uma **visão geral anual** quanto uma **análise detalhada de um mês específico**.
